# COMNETSAT Portfolio Optimization

This repository contains the Python implementation and experimental results of a study comparing three optimization algorithms for stock portfolio optimization:

- Genetic Algorithm (GA)
- Particle Swarm Optimization (PSO)
- Simulated Annealing (SA)

The study uses 45 stocks associated with the Indonesian LQ45 index and focuses on minimum-variance portfolio optimization.

## Files

- `TA_Portfolio_Optimization.ipynb` – Python implementation of the three algorithms.
- `COMNETSAT_100_Runs_All_Algorithms.csv` – Experimental results from 100 runs of each algorithm.

## Evaluation

The algorithms are compared based on portfolio variance, annualized return, annualized volatility, Sharpe ratio, and execution time.
